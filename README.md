# Teapot — Tea Pipeline Research Atlas

Teapot is an interactive 3D atlas of the ten stages of tea manufacture, from
plucking through to packaging. Each stage is a platform along a path you travel;
clicking one opens what physically happens there and where AI and machine
learning apply. Behind every stage sits the evidence — the research papers and
datasets backing each AI opportunity. A companion repository view collects that
whole corpus into one filterable table, browsable by stage, year, tag, source
tier, and scope. The site serves everything from a bundled corpus out of the
box, with Supabase as an optional backend for editing content without a
redeploy.
